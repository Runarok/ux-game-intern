# **2. What is a Game (Core Definition)**

A game is:

> **A system in which players engage in artificial conflict, defined by rules, that results in a quantifiable outcome.**

### Breakdown:

1. **System**

   * Interconnected elements (objects, mechanics, players)
   * Example: Tetris → blocks + score + rules

2. **Players**

   * External agents interacting with the system

3. **Artificial Conflict**

   * Competition, puzzles, time pressure
   * Not real-life consequences

4. **Rules**

   * Define interactions and constraints

5. **Quantifiable Outcome**

   * Clear results (win/loss/draw/score/state change)

---

# **3. Game vs Activity (Critical Distinction)**

### Examples:

#### Tic-Tac-Toe → Game

* Player decisions matter
* Strategy affects outcome

#### Chess → Game

* Deep strategy
* Skill-based dominance

#### Snakes & Ladders → *Not a Game (as per this framework)*

* Pure chance
* No meaningful decisions
* Outcome not tied to player skill

### Key Insight:

* **Games require meaningful player agency**
* Without decision-making → becomes an activity, not a true game

---

# **4. How to Fix Non-Games**

To convert something like Snakes & Ladders into a game:

* Add **choice**
* Introduce **risk vs reward decisions**

**Example change:**

* Multiple ladders → player chooses path

# **5. Core Functions of Games**

A game can serve multiple purposes:

1. **Entertainment**
2. **Simulation** (replicating real-world systems)
3. **Storytelling**
4. **Social Interaction**
5. **Problem Solving**
6. **Education**
7. **Self-Improvement**

### Example Mapping:

* The Sims → Simulation + Social + Entertainment
* Whispered World → Storytelling + Puzzle + Entertainment
* Operation Neptune → Education + Problem Solving
* Typing games → Self-improvement + Education

**Key idea:**
Not all games prioritize entertainment — design intent varies.

# **7. Player Types (Bartle’s Taxonomy)**

Players are not fixed types — think **spectrum**.

### 4 Core Types:

1. **Achievers**

   * Goals, scores, completion

2. **Explorers**

   * Discovery, secrets, systems

3. **Socializers**

   * Interaction with people

4. **Killers**

   * Competition, domination

**Reality:**

* Most players = **mix of types**
* One type may dominate behavior

# **8. Roles in Game Development**

## Game Designer

* Gameplay design
* Systems thinking
* Story, narrative, writing
* Directing player experience

## Game Programmer

* Implements logic
* Works with game engine
* Integrates tools
* Debugging

### Important:

* Designers decide **what**
* Programmers decide **how**

### Hybrid Role:

* People with both skills act as **bridge between design and tech**

# **12. Core Takeaways (What to Actually Remember)**

* A game = **system + rules + player interaction + conflict + measurable outcome**
* **Player choice is essential** — no choice → not a true game
* Games serve **multiple functions**, not just entertainment
* Players are **behavioral mixes**, not fixed types
* Game dev = **design + programming + many other disciplines**
* Designers shape experience, programmers implement it
* Games are both:

  * **Technical systems**
  * **Artistic mediums**
* Complexity is normal — not something to avoid, but to understand

---

# **13. Practical Thinking Frame (Use This Going Forward)**

Whenever you see or design a game, ask:

* Where is the **player decision**?
* What is the **conflict**?
* What are the **rules**?
* What is being **measured**?
* What is the **purpose** (function)?
* Who is the **player type**?
