# **1. Purpose of the Lesson**



* Understand **what game genres are**

* Learn **how to classify a game into a genre**

* Learn **how genres combine to create new ones**



---



# **2. Major Game Genres (Core Overview)**



> This list is **not exhaustive** — genres evolve.



### 1. Action



* Fast-paced, skill-based

* Combat, reflexes, movement

* Appeals to **achievers + killers**



---



### 2. Adventure



* Exploration, discovery

* Often open-world, crafting, upgrades

* Appeals to **explorers**



---



### 3. Casual



* Simple mechanics, short sessions

* Low cognitive load

* High repetition → addictive loops



---



### 4. Indie (Production Model, not gameplay)



* Independent studios (no publisher)

* More **creative freedom**, more risk

* Own IP, fewer constraints



---



### 5. MMO (Massively Multiplayer Online)



* Large number of players

* Social + competitive + cooperative

* Often includes monetization systems



---



### 6. Racing



* Speed + competition

* Modes: single-player, split-screen, online



---



### 7. RPG (Role-Playing Game)



* Character progression

* Inventory systems

* Player choices affect gameplaystory



---



### 8. Simulation



* Replicates real-world systems

* Simplified interaction, realistic behavior

* Often minimal or no story



---



### 9. Sports



* Real or fictional sports

* Competitive, multiplayer-focused



---



### 10. Strategy



* Planning, decision-making

* Control over multiple unitsresources

* High-level thinking over reflexes



---



# **3. Key Insight: Genres Are Not Rigid**



* A game can belong to **multiple genres simultaneously**



### Examples:



* Action + Adventure → *Action-Adventure*

* Action + Adventure + RPG → *Hybrid*

* Racing + Simulation → *Sim Racing*

* MMO + RPG → *MMORPG*



**Rule:**



* If multiple genre elements are **consistently present**, the game belongs to all of them



---



# **4. How to Classify a Game Genre (Core Framework)**



You **cannot rely on one factor** — classification is multi-dimensional.



### Primary Axes:



#### 1. Functions (Why the game exists)



* Entertainment

* Problem-solving

* Simulation

* Social, etc.



---



#### 2. Content (What’s inside)



* Mechanics

* Assets

* Story

* Systems



---



#### 3. Audience (Who it attracts)



* Achievers

* Explorers

* Socializers

* Killers



---



**Important:**



* These 3 alone are **not enough**

* You need supporting context



---



# **5. Supporting Classification Factors**



Use these to refine genre identification:



### 1. Number of Players



* Single-player → often adventure

* Multiplayer → actionMMOsocial

* MMO → defined by scale



---



### 2. Graphics & Camera View



* 2D vs 3D → changes mechanics

* First-person → actionsimulation

* Isometric → strategyRPGsimulation



---



### 3. Platform



* Mobile → simpler input, casual bias

* PC → complex controls (FPS, strategy)

* Console → controller-friendly design



---



### 4. Input System



* Touch → direct interaction

* Mousekeyboard → precision

* Controller → smooth movement, less precision aiming



---



### 5. Setting  Theme



* Fantasy → RPG, adventure

* Sci-fi → flexible (action, strategy, racing)

* Horror → often actionsurvival

* Open world → supports exploration genres



---



### 6. World Design



* Open world → exploration, RPG

* Lineartight → action-focused



---



### 7. Precedent (Existing Games)



* Compare with similar games

* Genres often evolve from existing patterns



---



# **6. Key Insight on Classification**



* No single feature defines a genre

* Genre = **pattern recognition across multiple factors**



---



# **7. Combining Genres (Design Approach)**



To create hybrid genres:



* Combine **mechanics**

* Combine **systems**

* Combine **player experiences**



**Consistency matters:**



* Features must be **integrated**, not randomly added



---



# **8. MDA Framework (Foundation for Genre Design)**



Game = **3 components**:



1. **Mechanics** → rules, systems

2. **Dynamics** → player interaction with systems

3. **Aesthetics** → player experiencefeeling



---



# **9. Game Aesthetics (8 Types)**



These define **what the player feels**:



1. **Sensation** → visuals, sound, feedback

2. **Fantasy** → immersion in another world

3. **Narrative** → story

4. **Challenge** → difficulty, obstacles

5. **Fellowship** → social interaction

6. **Discovery** → exploration

7. **Expression** → customization, identity

8. **Submission (Abnegation)** → time-pass, relaxation



---



# **10. Why Aesthetics Matter for Genre**



* Genres are not just mechanics

* They are **experiential patterns**



Example:



* RPG → fantasy + narrative + expression

* Casual → submission + simple challenge

* MMO → fellowship + progression



---

---



# **12. Core Takeaways (What to Remember)**



* Genres are **fluid, not fixed**

* Most games are **hybrids**

* Classification requires **multiple perspectives**

* Mechanics alone don’t define genre — **experience does**

* Player type + function + content → core base

* Supporting factors refine classification

* Aesthetics = **what players actually feel**

* Good design = **intentional combination**, not random mixing



---



# **13. Practical Thinking Frame**



When analyzing or designing a game:



* What **core genres** does it belong to?

* What **player experience (aesthetics)** is dominant?

* What **mechanics support that experience**?

* What **player types** does it attract?

* What **existing games** does it resemble?

* What **hybrid combination** is being used?
